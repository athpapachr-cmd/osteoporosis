# Knee OA: λειτουργικό prototype

**Μόνο δοκιμαστικά περιστατικά. Όχι κλινική χρήση ή στοιχεία πραγματικών ασθενών.**

Το prototype δεν είναι εγκατεστημένο στην παραγωγή. Εκτελείται στον υπολογιστή σου, μόνο στη διεύθυνση loopback. Δεν είναι ανεξάρτητο αρχείο HTML: απαιτεί τον μικρό τοπικό Python server και τα αρχεία CU-1 που περιλαμβάνονται στο δοκιμαστικό πακέτο ή στο repository.

## Εκκίνηση από τον βασικό φάκελο του πακέτου ή του repository

Απαιτείται Python 3.12. Η πρώτη εγκατάσταση κατεβάζει τις αναγραφόμενες εξαρτήσεις από το Python package index, όχι κλινικό περιεχόμενο. Η χρήση του εργαλείου δεν καλεί AI ή εξωτερική κλινική υπηρεσία.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r clinic_utilities/physio_referral_product/prototype/requirements.txt
python clinic_utilities/physio_referral_product/prototype/server.py
```

Στα Windows ενεργοποίησε το περιβάλλον με `.venv\Scripts\activate` αντί της δεύτερης γραμμής.

Άνοιξε στον browser:

```text
http://127.0.0.1:8765
```

Τερματισμός: `Ctrl+C` στο terminal. Εναλλακτική τοπική θύρα: `--port 8766`. Δεν υποστηρίζεται σύνδεση από άλλη συσκευή ή δημόσια φιλοξενία. Ένας μελλοντικός ελεγχόμενος preview server απαιτεί χωριστή εξουσιοδότηση και έλεγχο πρόσβασης.

## Πρώτη δοκιμή

1. Επιβεβαίωσε τη διάγνωση και επίλεξε πλευρά.
2. Επίλεξε πόνο, αδυναμία και λειτουργική δυσκολία, όπως σκάλες.
3. Δες το κείμενο και τη σχετική πρόταση. Το `+` προσθέτει την παρέμβαση, το `i` εμφανίζει την τεκμηρίωση χωρίς να αλλάζει θεραπεία.
4. Στο «Περισσότερα» δοκίμασε πρόσθετα ευρήματα, παρεμβάσεις, περιορισμό και κλινική σημείωση.
5. Πρόσθεσε βελονισμό για να εξετάσεις την εμφάνιση διαφωνίας οδηγιών, όχι ως κλινική σύσταση αυτής της δοκιμής.
6. Επεξεργάσου το κείμενο και μετά άλλαξε πλευρά. Οι αλλαγές σου πρέπει να διατηρούνται, αλλά η εξαγωγή να απαιτεί συμφιλίωση.

Η Αντιγραφή και η Εκτύπωση/PDF φέρουν πάντα ένδειξη δοκιμαστικού, μη κλινικού κειμένου. Το PDF χρησιμοποιεί την εκτύπωση του browser. Δεν υπάρχει ξεχωριστός PDF server.

## Τι αξιολογούμε

Ταχύτητα και ευκολία, σαφήνεια των έξι ενδείξεων τεκμηρίωσης, χρήσιμες προτάσεις χωρίς ενόχληση, φυσική ελληνική γλώσσα, διατήρηση πρόσθετων επιλογών και χειροκίνητου κειμένου. Κεντρικό ερώτημα: **τι πρέπει να αφαιρεθεί;**

Η δοκιμή σε στενό desktop viewport δεν αντικαθιστά πραγματικό Safari/VoiceOver. Οι σύνδεσμοι αφορούν τις πηγές συνολικά, όχι επαληθευμένο αριθμό σύστασης ανά ισχυρισμό. Η κλινική βάση κληρονομείται από το παγωμένο Step 2. Οι νέες ελληνικές περιλήψεις είναι μεταφράσεις προβολής και παραμένουν προς κλινική αποδοχή. Δεν διενεργήθηκε ανεξάρτητη κλινική ανασκόπηση από την υλοποίηση του UI.

## Αρχιτεκτονική και όρια

Η πραγματική μηχανή CU-1 ελέγχει τη δομημένη κατάσταση. Το prototype αξιοποιεί τις παγωμένες συναρτήσεις του Step 3 για σύνθεση και του Step 4 για τεκμηρίωση/προτάσεις. Αυτή η εξάρτηση από design validators είναι ρητή και προσωρινή για μη παραγωγική δοκιμή. Πριν από παραγωγή απαιτείται χωριστή εξαγωγή/ενσωμάτωση σε runtime modules, επανέλεγχος ασφάλειας, κλινική αποδοχή και ανεξάρτητο review.

Δεδομένα παραμένουν μόνο στη μνήμη. Δεν υπάρχει βάση ασθενών, localStorage/sessionStorage, analytics, λογαριασμός, χρέωση ή αποστολή σε AI. Τα αρχεία κώδικα/εξαρτήσεων δεν είναι αποθήκευση παραπεμπτικών. Μόνο η ρητή εξαγωγή από τον χρήστη δημιουργεί αντίγραφο στο clipboard ή στην εκτύπωση/PDF.

Η επιλογή true locking, το dry needling, η διαχείριση βάρους και το βοήθημα βάδισης δεν ενεργοποιούνται κρυφά ως νέες επιλογές: διατηρούνται τα ήδη καταγεγραμμένα όρια των προηγούμενων βημάτων.

## Επαναλήψιμοι έλεγχοι

```bash
python clinic_utilities/physio_referral_product/prototype/test_server.py
python -m pip install playwright==1.55.0
python -m playwright install chromium
python clinic_utilities/physio_referral_product/prototype/test_browser.py
```

Ο έλεγχος browser εκκινεί τον πραγματικό loopback server και την πραγματική μηχανή CU-1. Η σκόπιμη αποτυχία δικτύου είναι αρνητικό σενάριο ασφάλειας, όχι υποκατάστατο του κλινικού ελέγχου. Τα αποτελέσματα και οι περιορισμοί καταγράφονται στα operational canonicals. Επιτυχία των tests δεν ισοδυναμεί με κλινική πιστοποίηση, πλήρη συμμόρφωση προσβασιμότητας ή ανεξάρτητο review.
