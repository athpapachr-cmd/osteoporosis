Privacy στο pilot

Το GitHub repository είναι public. Η φόρμα δεν στέλνει δεδομένα στο GitHub.

  • Μην εισάγεις όνομα, ΓεΣΥ/EMR ID, DOB, τηλέφωνο ή email.
  • Μην επικολλάς raw Heidi transcript ή αναγνωρίσιμη κλινική σημείωση.
  • Τα drafts του prototype μένουν στο localStorage του browser και δεν είναι κρυπτογραφημένα.
  • Για πραγματική production χρήση με αναγνωρίσιμα δεδομένα απαιτείται ξεχωριστό secure/private storage και access control.
