# Cockpit — Πρωτότυπο ενιαίας κλινικής επίσκεψης

**Δοκιμαστικό, μόνο συνθετικοί ασθενείς — 10/10/2026.**

## Άνοιγμα
Ανοίξτε το `index.html` στον browser. Δεν απαιτείται server, σύνδεση ή clinical data key. Δεν υπάρχουν κλήσεις δικτύου, συνδέσεις με πραγματικά συστήματα ή μόνιμη αποθήκευση.

## Τι δοκιμάζουμε
- Επιλογή από σημερινά/επόμενα ραντεβού ή πρόσφατους φακέλους και αναζήτηση ονόματος (συμπεριλαμβανομένων δύο ομώνυμων συνθετικών ασθενών).
- Άμεση μεταφορά επιλεγμένου ασθενούς στην επίσκεψη χωρίς δεύτερη αναζήτηση.
- Μη επιβεβαιωμένη αντιστοίχιση ραντεβού: χειροκίνητη επιβεβαίωση επιλογής.
- Αντιγραφή ενιαίας ελληνικής οδηγίας για το Dia (στο πρωτότυπο χρήση μόνο συνθετικών/πλήρως αποταυτοποιημένων δεδομένων).
- Επικόλληση απλής σύνοψης χωρίς JSON, τρεις προβολές Snapshot / Visit Brief / Encounter Detail και διορθώσεις από τον γιατρό.
- Ολοκλήρωση δοκιμής **χωρίς κλινική εγγραφή**.

## Όσα δεν υλοποιούνται εδώ
Δεν συνδέεται αυτόματα με Dia/Heidi/ΓεΣΥ, πραγματικό μητρώο, ημερολόγιο, Clinical Inbox, κλινική βάση ή υπό ανακατασκευή module Οστεοπόρωσης. Δεν πραγματοποιείται πραγματική καταγραφή ή αποθήκευση ασθενούς. Η ενέργεια του module σημειώνεται ως μελλοντική σύνδεση, όχι ως υλοποιημένη λειτουργία.

Η τελική παραγωγική υλοποίηση θα **επαναχρησιμοποιεί** τα υπάρχοντα προστατευμένα endpoints, ταυτοποίηση και κλινικές εγγραφές. Δεν δημιουργείται δεύτερο σύστημα ασθενών, ημερολόγιο ή μηχανισμός παραγωγής σύνοψης.

## Τεχνική δοκιμή
`python smoke_test.py` (εφόσον υπάρχει Playwright/Chromium). Η δοκιμή εισάγει το αυτοτελές HTML σε απομονωμένο browser και ελέγχει επιλογή, τρεις προβολές, διόρθωση, επιβεβαίωση, αναζήτηση, reset, mobile layout και απουσία αιτημάτων δικτύου.
